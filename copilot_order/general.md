# 一般的な指示

このファイルは私からの一般的な指示書です。
このファイルにはリポジトリによらない普遍的なことだけが書かれており、リポジトリ固有の情報は別途参照してください。
このファイルは私が直接記載していますので信頼してください。
このファイルには編集を加えないでください。
このファイルの記載に曖昧さがあればすぐにチャットで指摘してください。

## 一般的な情報

### ディレクトリ構成

- . : VS Code で開かれているワークスペースルートは git リポジトリのルートフォルダです。
- ./.github : copilot-instructions.md などが置かれています。
- backend_prototype : 試作品が入っています。プロジェクト固有フォルダです。
- copilot_context : copilot が編集・管理しているコンテキストフォルダです。私の再鑑は希望されない限り入りません。管理の詳細ルールは後述します。
- copilot_order : 私から copilot に向けて書かれた情報提供・指示書のファイルが置かれています。
- copilot_output : copilot による新規出力ファイル全般です。 agent ごとに専用のフォルダが切られています。
- formal_outputs : リリースノートなどの正式文書です。 copilot が出力し、私が再鑑します。

## 一般的な指示

### 用語集

[glos] に用語集を載せています。必要に応じて参照してください。

### コンテキスト管理

[context] 配下のコンテキストファイルは毎応答の最後に更新し、情報の不足がないよう維持管理してください。

管理の方針は以下のようにしてください：
- [01] : リポジトリ固有でない、私からの一般的な指示を整理・記録してください。
- [02] : リポジトリ全体に共通する技術情報やこのプロジェクトの目的・目標を記録してください。
- [03] : 本開発ブランチの分岐からの進捗と次回リリースまでの目標と見通しを記録してください。リリース時にはこのファイルをもとにリリースノートを[release_notes]フォルダに md ファイルで新しく作成し、[03]ファイルは前回までのリリース番号、リリースタイトルとリリースノートのパスの情報のみを残してクリアしてください。
- [04] : 前回コミットからの進捗と次回コミットまでの目標と見通しを記録してください。コミット時にはこのファイルをもとにコミットメッセージを[commit_messages]フォルダに md ファイルで新しく作成し、[04]ファイルは前回までのコミット番号、コミットタイトルとコミットメッセージファイルのパス情報のみを残してクリアしてください。
- [05] : 直近の話題を記録してください。ファイルサイズの合計が 10000 字を超えないよう不要になった内容は適宜削除してください。

### subagent の呼び出しに当たって

- subagent の呼び出しは推奨されます。必要に応じて呼び出してください。
- custom subagent を呼び出した際は、`templates/subagent_review.md` に沿ってレビューを行い、`<yyyyMMdd>_<agent_name>_review.md` というファイル名で出力してください。

### あなたの権限について

- あなたの権限は「あらゆる参照を自動許可する」「変更は GitHub Copilot のデフォルト設定による」という方針で設定されています。
- ただの参照操作でユーザ許可が必要になったときは、 `./formal_outputs/copilot_controls/permission.md` の必要な権限の一覧の項目に追記してください。ファイルや項目がなければ作成してください。

### プロジェクトへの作業に当たって

- ソースコード変更を伴う操作の前に、実装方針を文書化して開発者に確認してください。
- ただし、コンテキストファイルの追記・書き換えは確認不要です。
- `copilot_output` へのファイル新規作成は確認不要です。この際 `copilot_context_02_repository.md` への導線追記も合わせて行ってください。
- cargo check / cargo build / cargo test は常時許可されています。ビルド確認及びテストはソース変更後に常時実行してかまいません。
